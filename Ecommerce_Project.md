# E-commerce Data Analysis

## Objective
Analyze e-commerce sales data to understand customer behavior, product performance, and sales trends.

## Tools Used
- Excel (Data Cleaning, Pivot Tables, Formulas)
- SQL (Data Queries, Customer Analysis)
- Tableau (Dashboard and Visualization)

## Key Insights
- Top-selling products and categories identified
- Customer purchase patterns analyzed
- Monthly and seasonal sales trends highlighted
- Recommendations for improving sales performance
